エージェントとツール連携 — モデルが外に手を伸ばす

エージェントは、モデルに道具を持たせる仕組みです。誰が判断し、誰が道具を持ち、手順をどこまで固定するか。その線引きがこのマップの中身です。

上から下へ、指示を受けたモデルが道具を使い、結果を覚え、手順に収まるまでの5段です。

知識を引くときは → 検索経路 入出力の検査は → 安全と統制の関門 実行の記録は → 観測と評価の配線

同じ段を争うもの

手順が事前に決まっているなら Prompt Flows や Step Functions、決まっていないならエージェントに任せます。道具が自分のものか外部のものかで、アクショングループと MCP が分かれます。

どこを読むか

段候補深掘り
指示の管理 Prompt Management / Prompt Flows 1.6
判断と手順 Bedrock Agents / Step Functions / Lambda 2.1
道具の口 アクショングループ / MCP 2.1
社内システムとの統合 API Gateway / Q Business 2.3
開発と実行 AgentCore / Strands 2.5

このマップだけでは足りない場面: エージェントが引く知識そのものの精度は 検索経路、ツール呼び出しの記録と追跡は 観測と評価の配線 を見てください。

このマップが束ねるタスクの問題

番号はこのマップが束ねる4タスクの問題です。図に出るサービスと一対一ではありません。クイズの出題範囲に番号を入力して解いてください。

問題データを読み込めませんでした。問題番号の一覧はオンラインで開き直すと表示されます。
