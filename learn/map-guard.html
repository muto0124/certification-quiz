安全と統制の関門 — どこで何を止めるか

同じ「アクセス制御」でも、効く場所が違います。1 つのリクエストがどの関門を順に通るかを押さえると、選択肢の取り違えが減ります。

上から下へ、1 つのリクエストが通る関門です。WAF は通信を、Guardrails はプロンプトと応答を、KMS と Macie は保存されたデータを見ます。

モデルの呼び出し自体は → 呼び出しと推論基盤 誰が何をしたかの記録は → 観測と評価の配線

同じ段を争うもの

Guardrails はリアルタイムの制御、Comprehend はエンティティの抽出、Macie は保存済みデータの検出です。PrivateLink は通信経路を閉じ、SCP と IAM は許可の範囲を決めます。

どこを読むか

段候補深掘り
入出力の検査 Bedrock Guardrails / Comprehend / ApplyGuardrail 3.1
データの保護 KMS / Macie / Lake Formation 3.2
組織の統制 SCP / IAM / PrivateLink 3.3
入口の防御 AWS WAF / Cognito 3.4

このマップだけでは足りない場面: 誰が何をしたかを後から追うときは 観測と評価の配線、モデルの呼び出し自体は 呼び出しと推論基盤 を見てください。
